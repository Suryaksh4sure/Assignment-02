# Assignment-02 — Sippline Landing Page

## About the Project

This project recreates a landing page for Sippline — “Glass ka Mask” using HTML and CSS. It features a gradient background, navigation bar, call-to-action buttons, decorative shapes, and a diamond-shaped image created using CSS transforms and `clip-path`.

## Features

- Responsive landing page design
- Gradient background and geometric decorations
- Navigation bar with Shop, About, Blogs, and Contact links
- Call-to-action buttons
- Diamond-shaped image with a white border
- CSS `clip-path` for geometric styling
- Responsive layout for desktop, tablet, and mobile screens

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Media Queries
- CSS `clip-path`, transforms, and gradients
